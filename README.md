# horaires-shabbat

מחולל עלון זמני התפילות השבועי של **בית הכנסת מרום נווה** (רמת גן).

## הרצה

```bash
pip install -r requirements.txt
python horaires_shabbat.py              # השבת הקרובה
python horaires_shabbat.py 2026-11-04   # שבת אחרי תאריך מסוים
python horaires_shabbat.py --legacy     # העיצוב הישן (כתיבה על template.jpg)
```

התוצאה: `output/horaires_*.jpeg` + `output/latest-schedule.jpg` (לפרסום ב-GitHub Pages) וגם
`output/latest-schedule.png` (מתאים להעתקה לקבוצת ווטסאפ). גודל: 1080 פיקסלים רוחב, לאורך.

## העיצוב הדינמי (ברירת מחדל)

- חישובי הזמנים **לא השתנו** (`calculate_times`, אקסל, Hebcal, JewishCalendar, מולד, ברכת הלבנה, תקופה, צומות).
- כותרת: הלוגו (נחתך מתוך `resources/template.jpg`), שם הפרשה, תאריך לועזי ועברי.
- 3 תמונות קטנות של הפרשה — **נוצרות ב-AI בזמן ההרצה** (ראו למטה). אם ה-AI לא זמין — תמונות מקומיות
  מ-`assets/parsha/<slug>/` אם קיימות, ואחרת אריחים דקורטיביים עם מגן דוד (אין קריסה).
- עברית מימין לשמאל: הסקריפט מסדר את האותיות בעצמו (python-bidi + מנוע BASIC של Pillow), ולכן
  **אותו קובץ נותן תוצאה זהה ב-GitHub ובמחשב המקומי** — אין צורך יותר ב"הפוך על הפוך" ולא בגרסת LOCAL.
  רשת ביטחון: אם במחשב מסוים העברית בכל זאת יוצאת הפוכה, אפשר להריץ עם `HEBREW_RENDER=raqm`.
- אם העיצוב הדינמי נכשל מסיבה כלשהי — הסקריפט חוזר אוטומטית לעיצוב הישן על ה-template.
- טקסטים קבועים (שמות המרצים, הערות, שחרית 06:30/06:00, כתובת) נמצאים בראש `dynamic_design.py`.

## תמונות הפרשה — יצירה ב-AI (קובץ `ai_images.py`)

- **כל 3 התמונות נוצרות ע"י בינה מלאכותית** — הן לא לקוחות מאתר או מיצירה קיימת.
- לכל אחת מ-54 הפרשות מוגדרים ב-`THEMES` שלושה נושאים: כיתוב בעברית + תיאור סצנה באנגלית שנשלח ל-AI
  (בסגנון צבעי מים, גווני כחול-טורקיז, לבוש צנוע, בלי טקסט, בלי תיאור של הקב"ה). אפשר לערוך חופשי.
- ספק ה-AI נבחר במשתנה `AI_IMAGE_PROVIDER`:
  - `pollinations` (ברירת מחדל) — שירות חינמי, בלי מפתח. מגבלה: בערך בקשה אחת ל-15 שניות (הסקריפט ממתין
    לבד), ובפינת התמונה מופיע סימן מים קטן "pollinations". האיכות והדיוק משתנים.
  - `openai` — דורש סוד `OPENAI_API_KEY` ב-GitHub (בתשלום, בערך 0.04$ לתמונה). בלי סימן מים.
- התמונות נשמרות זמנית ב-`output/ai_cache/` (לא נכנס ל-git) כדי לא לייצר שוב באותו שבוע.
- `PARSHA_IMAGE_SOURCE`: `ai` (ברירת מחדל) / `local` (רק תמונות מקומיות) / `none` (רק אריחים דקורטיביים).
- התיקייה `assets/parsha/` אופציונלית לגמרי — רק אם רוצים תמונות קבועות משלכם כגיבוי
  (`1.jpg`,`2.jpg`,`3.jpg` + `meta.json`, ה-slugs ב-`parsha_assets.py`).
